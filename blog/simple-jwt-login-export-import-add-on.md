The `beta` version of the Export-Import add-on is out. [Download it](https://github.com/simple-jwt-login/export-import/archive/refs/heads/master.zip) for **free** from GitHub and try it.

## Installation[​](#installation "Direct link to Installation")

1. Download the add-on from [GitHub](https://github.com/simple-jwt-login/export-import/).
2. Upload the zip file to WordPress.
3. Activate the plugin.
4. Export or import your settings.

See the [Export-Import add-on documentation](/docs/export-import.md) for details.
