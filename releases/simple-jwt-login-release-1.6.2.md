The version `1.6.2` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds more options for creating users.

## New Features[​](#new-features "Direct link to New Features")

* Pass the plain text password to the register user hook
* Add an option to give new users a random password
* Add the "Initialize force login after register" option, which continues with autologin after registration
* Add more options for creating new users

## Improvements[​](#improvements "Direct link to Improvements")

* Update the documentation
