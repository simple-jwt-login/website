The version `3.3.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release sanitizes every text shown by the plugin, updates translations and makes random passwords stronger.

## Security[​](#security "Direct link to Security")

* Sanitize all texts displayed by the plugin
* Improve the random password algorithm for better security

## Improvements[​](#improvements "Direct link to Improvements")

* Add missing translation texts and update all translations
* Update the Bootstrap libraries

***

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
