The version `2.5.2` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

A maintenance release that adds permission callbacks to the API routes and starts the session only when needed.

## Bug Fixes[​](#bug-fixes "Direct link to Bug Fixes")

* Add a permission callback to the API routes
* Start the PHP session only when reading the JWT from the session is enabled

***

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
