The version `3.4.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release introduces Protect Endpoints, which lets you require a valid JWT to access your WordPress REST endpoints.
<!--truncate-->

## New Features

- Add **Protect Endpoints**. Choose which REST endpoints need a valid JWT and which stay public.

Read more about [Protect Endpoints](/docs/protect-endpoints/).

## Improvements

- Improve code coverage
