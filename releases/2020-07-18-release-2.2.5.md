The version `2.2.5` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds login by username and a beta feature for accessing private endpoints with a JWT.
<!--truncate-->

## New Features

- Log in by username (`user_login`)
- Beta: access private WordPress REST endpoints with a JWT
