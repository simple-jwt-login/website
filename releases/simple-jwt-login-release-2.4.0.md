The version `2.4.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds the `redirectUrl` parameter and URL variables for autologin.

## New Features[​](#new-features "Direct link to New Features")

* Add the `redirectUrl` parameter
* Add variables you can use in URLs

Read more about [autologin](/docs/autologin.md).

## Bug Fixes[​](#bug-fixes "Direct link to Bug Fixes")

* Fix a session start warning

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
