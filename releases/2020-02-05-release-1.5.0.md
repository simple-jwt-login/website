The version `1.5.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release lets you delete users with a JWT and set a custom namespace for the API routes.
<!--truncate-->

## New Features

- Delete users based on a JWT
- Set a custom namespace for the API routes
- Rename the create user route, while keeping the old route for backward compatibility

Read more about [deleting users](/docs/delete-user/).

## Improvements

- Refactor the routes section
