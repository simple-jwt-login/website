The version `3.2.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release passes the user to the login and register hooks and lets the register endpoint return a JWT.

## New Features[​](#new-features "Direct link to New Features")

* Pass the user to the `simple_jwt_login_register_hook` and `simple_jwt_login_login_hook` hooks ([#10](https://github.com/nicumicle/simple-jwt-login/issues/10))
* Add an option to return a JWT from the register user endpoint ([#9](https://github.com/nicumicle/simple-jwt-login/issues/9))

Read more about [hooks](/docs/hooks.md) and [registering users](/docs/register-user.md).
