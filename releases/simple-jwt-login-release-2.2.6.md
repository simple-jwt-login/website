The version `2.2.6` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds certificates for signing JWTs and lets users authenticate with their username.

## New Features[​](#new-features "Direct link to New Features")

* Use certificates to encode and decode JWTs
* Add the username to the JWT payload
* Authenticate on the `/auth` endpoint with the WordPress username

## Bug Fixes[​](#bug-fixes "Direct link to Bug Fixes")

* Fix saving the JWT algorithm

***

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
