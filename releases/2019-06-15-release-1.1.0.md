The version `1.1.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds more ways to control who can log in and register.
<!--truncate-->

## New Features

- Limit login and registration by IP address
- Allow registration only for emails from specific domains
- Make requests without Auth Codes
