The version `2.5.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release lets you change the parameter name used to read the JWT from the URL, session, cookie and header.

* Change the key used to read the JWT from the URL, session, cookie and header
