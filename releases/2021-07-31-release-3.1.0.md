The version `3.1.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds endpoints for sending a reset password code and changing the password.

## New Features

- Add the reset password and send reset password code endpoints

Read more about [resetting passwords](/docs/reset-password/).
