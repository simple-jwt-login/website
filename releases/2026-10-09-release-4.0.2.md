The version `4.0.2` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

A small maintenance release that fixes the WooCommerce integration and confirms compatibility with WordPress 7.1.
<!--truncate-->

## Bug Fixes

- Fix the WooCommerce integration so JWT-authenticated requests to the WooCommerce REST and Store APIs work as expected ([#177](https://github.com/nicumicle/simple-jwt-login/issues/177))

Read more about the [WooCommerce integration](/docs/integrations/third-party/woocommerce/).

## Compatibility

- Tested with WordPress 7.1
