The version `1.6.1` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release lets the plugin read the JWT from cookies and the PHP session.

## New Features[​](#new-features "Direct link to New Features")

* Read the JWT from `$_COOKIE` and `$_SESSION`

## Improvements[​](#improvements "Direct link to Improvements")

* Improve how the plugin detects if the database option needs to be created or updated
* Update the README

***

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
