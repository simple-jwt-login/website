The version `2.1.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds CORS support and more options for autologin redirects and Auth Codes.
<!--truncate-->

## New Features

- Add support for CORS
- Include the login link request parameters in the redirect URL
- Pass the initial request data to the `simple_jwt_login_redirect_hook` hook
- Add an expiration date and a user role to Auth Codes

Read more about [CORS](/docs/cors/) and [Auth Codes](/docs/auth-codes/).
