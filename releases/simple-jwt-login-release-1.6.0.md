The version `1.6.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds hooks for login and registration and lets you send the JWT in a header.

## New Features[​](#new-features "Direct link to New Features")

* Add hooks for login, register and create user
* Send the JWT in a header
* Read the JWT parameter name case-insensitively

Read more about [hooks](/docs/hooks.md).

## Bug Fixes[​](#bug-fixes "Direct link to Bug Fixes")

* Fix saving settings with the minimum number of parameters (no Auth Codes when all options are disabled)

## Improvements[​](#improvements "Direct link to Improvements")

* Update the README
