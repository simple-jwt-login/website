The version `2.2.7` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds support for base64-encoded decryption keys and fixes a couple of warnings.

## New Features[​](#new-features "Direct link to New Features")

* Store a base64-encoded decryption key and let the plugin decode it when needed

## Bug Fixes[​](#bug-fixes "Direct link to Bug Fixes")

* Fix the warning "`register_rest_route` was called incorrectly"
* Ignore white space when reading the JWT from the header

***

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
