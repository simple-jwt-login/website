The version `2.0.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

A major release with a new settings interface and routes for generating and refreshing JWTs.
<!--truncate-->

## New Features

- New settings interface
- Enable or disable each hook
- Add a route for generating a JWT
- Add a route for refreshing an expired JWT
- Set a custom `user_login` for new users
- Return the WordPress user in the create user response

Read more about [authentication](/docs/authentication/).
