The version `3.4.1` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release lets users change their password with a JWT and improves the new Protect Endpoints feature.
<!--truncate-->

## New Features

- Change the user password using a JWT
- Authenticate with the hashed password stored in the database

Read more about [resetting passwords](/docs/reset-password/).

## Bug Fixes

- Fix Protect Endpoints conflicting with `wp-admin` actions
- Check that the user role exists before using it

## Improvements

- Improve the Protect Endpoints logic

Read more about [Protect Endpoints](/docs/protect-endpoints/).
