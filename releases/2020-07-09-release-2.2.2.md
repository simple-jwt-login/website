The version `2.2.2` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

A maintenance release that improves how the plugin loads its scripts and styles.
<!--truncate-->

## Improvements

- Add the plugin version to the JavaScript and CSS files, so browsers load the latest version after an update
- Change the path for the JavaScript and CSS files
- Change the load order of the JavaScript files

---

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
