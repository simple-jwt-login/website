The version `2.2.3` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds a toggle for all hooks and fixes a CORS issue.

## New Features

- Add a toggle to enable or disable all hooks at once

## Bug Fixes

- Fix a CORS issue
