The version `3.4.3` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

A maintenance release that confirms compatibility with WordPress 5.9 and fixes an empty Authorization header.
<!--truncate-->

## Bug Fixes

- Do not add an empty JWT to the `Authorization` header

## Compatibility

- Tested with WordPress 5.9

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
