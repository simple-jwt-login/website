The version `2.2.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds an endpoint for validating tokens.
<!--truncate-->

## New Features

- Add the `/auth/validate` endpoint. It validates a token and returns details about the user in the JWT.

Read more about [validating tokens](/docs/validate-token/).
