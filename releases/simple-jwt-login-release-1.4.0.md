The version `1.4.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release adds error codes and many improvements to the settings page.

## New Features[​](#new-features "Direct link to New Features")

* Add codes to errors

Read more about [error codes](/docs/error-codes.md).

## Bug Fixes[​](#bug-fixes "Direct link to Bug Fixes")

* Fix validations
* Keep the settings values when there is an error

## Improvements[​](#improvements "Direct link to Improvements")

* Allow saving settings without Auth Codes when they are not used
* Improve the example URL generators
* Small UI changes
* Refactor the code
* Update the README

***

If you encounter any issues after updating, please open an [issue](https://github.com/nicumicle/simple-jwt-login/issues) on GitHub.
