The version `2.6.0` has been released today on [WordPress](https://wordpress.org/plugins/simple-jwt-login).

This release lets autologin respond with JSON instead of redirecting.
<!--truncate-->

## New Features

- Add a `No Redirect` option for autologin. The endpoint then responds with JSON instead of redirecting.
- Add a hook for `No Redirect`, so you can customize the autologin response

Read more about [autologin](/docs/autologin/).
