##  Shortcode Configuration

To configure the shortcode, use the options provided by this plugin for generating the "Continue with Google" button:
```
[simple-jwt-login-oauth provider="google"]
```

The shortcode includes the following customization options:
- **provider**: `required` Specifies the provider name. For Google, use `google`.
- **background**:  defines the background color style (for example, `#c8c8c8`)
- **color**: specifies the text color style (for example, `#f2f2f2`)
- **width**: sets the button width (for example, `250px`)
- **height**:  determines the button height (for example, `40px`).
- **border**: specifies the button border style (for example, `1px solid #000`)


Example of full shortcode:
```
[simple-jwt-login-oauth provider="google" background="#c8c8c8" color="#f2f2f2" width="250px" height="40px" border="1px dotted blue"]
```
